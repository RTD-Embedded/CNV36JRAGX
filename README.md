## Using this Package

This package demonstrates how to install Linux for Tegra on the Nvidia Jetson 
Orin AGX with the required changes for full functionality of the CNV36JRAGX
carrier card. This package is written for L4T Jetson Linux R36.3.0 Release and
uses scripts that pull this source.

Assume we are in the working directory on our Ubuntu 22.04 PC

This package is supplied with configuration scripts for pulling the NVIDIA 
source and preparing it for deployment on the CNV36JRAGX carrier card series. 
As the process involves pulling, extracting, and building the kernel, it 
would be best to run this on machine with a Performant CPU and disk to save significant time.

## Running the Shells to Build an Image

Below is a description of the shell scripts that will execute and configure 
the image for the NVIDIA Jetson.Some will require root privledges to execute.
These scripts will give you a frame work on how to modify the kernel build 
process for your usage. 

	Build-RTD-Image.sh - This script requires internet access and root
		privleges to execute. It will prompt you for root access when
		needed. It does the following process:
		1. The Build Process involves downloading the NVIDIA
		source tree, a linux kernel, and example filesystem. 
		2. It will Modify the source tree as needed by NVIDIA
		3. Modify the Kernel configuration and root file system as needed by RTD
		4. Build a Linux Kernel Using that configuration.
	
		The output directory Linux_For_Tegra is the output of this shell
		required for Flash-RTD-Image.sh. Some of the above steps will be
		skipped if the user has previously run this step. Remove the
		generated folders for a clean rebuild if desired with cleaner.sh
		for a fresh build.

	Flash-RTD-Image.sh - This script requires root privilages. and will
		perform the following actions. It requies the Jetson be connected
		via USB on CN17 to the host.
		1. Check if there is an attached NVIDIA jetson in recovery Mode.
		2. Select which image to use with a number input.
		3. Flash the Selected Image generated by Build-RTD-Image.sh
	
		This process will take some time. The Flashing process attempts various
		methods for placing the image on the device. It may report errors that
		are not relevant for your build, and continue with the flashing process.

	cleaner.sh - a small helper script that will remove all potentially generated
		folders from the Build-RTD-Image.sh tool. This will help with re-running
		the build script from a clean starting point.

## Loading an Image onto the NVIDIA Jetson

To flash the Jetson you need to connect the programing cable from a usb port
on a computer with a kernel image to CN17. The Jetson also needs to be setup
in recovery mode.

	----- Setting the Jetson to recovery mode -----
	1. Apply Power to the Jetson
	2. Place the Jetson into soft-off by pressing the power button for 5 seconds
	3. Press the power button again for 10 seconds
	4. You should now see the Nvidia APX device in your USB listing on your host computer.

## Known Limitations

change to a different distribution, but different versions of Ubuntu may be fine.

the Nvidia Jetson Orin AGX. If you would like to instead install the image to an external drive,
